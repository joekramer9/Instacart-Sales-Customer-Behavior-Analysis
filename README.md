# Instacart-Sales-Customer-Behavior-Analysis
(SQL + Power BI Dashboard)
[Google Drive link to project](https://drive.google.com/drive/folders/1QP9G1vKxYcniGQE8J_SkcajtkG2Ro4mg?usp=sharing)
Built an interactive Power BI dashboard to analyze sales performance and customer purchasing behavior using an anonymized Instacart dataset sourced from Kaggle. The dashboard highlights key business metrics including total orders, products sold, and reorder rate, while enabling dynamic exploration of trends across departments, products, and time of day.
Prior to visualization, the dataset was cleaned and structured using Microsoft SQL Server. This included joining multiple relational tables (orders, products, departments, and order details), handling null values, standardizing field formats, and creating aggregated views to support efficient analysis. These transformations ensured data consistency and optimized performance when importing into Power BI.
Key features include:
	•	KPI cards summarizing total orders, total products sold, and overall reorder rate
	•	Department-level performance analysis to identify high-volume and high-retention categories
	•	Time-based trend analysis showing order volume by hour of day
	•	Top product ranking visualization based on sales volume
	•	Dynamic filtering by department, order hour, and reorder status for deeper analysis
	•	Identification of the highest-performing department by reorder rate using DAX measures and ranking logic
This project demonstrates proficiency in SQL, Power BI, data modeling, DAX calculations, and designing dashboards that communicate actionable business insights from large-scale transactional data.

Data Source:
[Instacart Market Basket Analysis Dataset (Kaggle)](https://www.kaggle.com/datasets/psparks/instacart-market-basket-analysis)
